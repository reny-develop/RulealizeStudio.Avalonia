# An example

The example counts to ten, one to three at a time: a window with the total and three buttons, and
the rules saying which of them can be pressed. It is made in the folder as an application of its
own, and built. Commit it as it comes, in Source Control, so that every change after it is read
against it.

The first time, what it is built with is fetched, after asking.

It is in the RulealizeStudio.Avalonia view, under its name: its screen, what it should do, and its
test cases.
