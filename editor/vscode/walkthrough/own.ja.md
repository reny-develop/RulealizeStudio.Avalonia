# 自分のもの

新しいアプリケーションは、まだ何もないウィンドウと、まだ何も書かれていない仕様を持ったフォルダーです。アプリケーションのことはすべて、アクティビティ バーの RulealizeStudio.Avalonia ビューにあります — 画面、仕様、そしてルールができてからのテストケース。

画面は、そのアプリケーションのウィンドウとして実際の姿で開きます。ビルドが読み込むコントロールを置きたい場所へドラッグし、動かし、角をつまんで大きさを変え、削除し、言葉を付けられます — XAML を読む必要はありません。ウィンドウと仕様は増やせます。ビューの **画面** と **仕様** の行の + で一つずつ加わり、行のゴミ箱のボタンで削除できます。ウィンドウがいつ現れていつ消えるかは仕様に書き、ほかと同じようにルールに結びつけます。画面と仕様に書いたことは、あなたのものです。コミットはいつもの場所で行ってください。エージェントがそこからルールを書いたら、ビューの画面と仕様の下に、あなたが作ったもののうち、ルールに結びつけた以外に変わったところが出ます。ルールができてからは例と同じです。テストケースを読み、気になったところはエージェントに直すよう頼み、それが何をしたかを読みます。
