# A change

A change is asked of whatever agent you use, in its own place and in your own words — *count to
twelve*, say. The extension writes nothing down for it.

Once the agent has changed the rules, the test cases the change touched head the list, under
**Since the last commit**, marked **Changed**, **Added** or **Removed**. Choose one, and its expected
result before the change and after it stand side by side, each on the application's own window.

It stays there until you commit, whether or not the agent derived the test design again. Commit it
in Source Control when it is what you meant; to throw it away, ask the agent to, or **Discard
Changes** there.
